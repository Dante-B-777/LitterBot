# Sensor UI Integration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Wire RPLidar `/scan` and RealSense `/camera/color/image_raw` into the existing UI — live camera feed in `camera-panel`, status dots for both sensors, and scan metadata in `lidar-panel`.

**Architecture:** Subscribe to `/scan` and `/camera/color/image_raw` in `ui_server.py` (the existing ROS2 node that already bridges topics to the browser WebSocket). Add two new WebSocket message types: `sensor_status` (for lidar heartbeat + scan stats) and `cam_frame` (base64-JPEG camera frame). The frontend handles both types to update status dots and panels. No new ROS2 nodes needed — this is additive to `ui_server.py`.

**Tech Stack:** Python `sensor_msgs/LaserScan`, `sensor_msgs/Image`, Pillow (PIL) for JPEG encoding, numpy for image array conversion, existing FastAPI/WebSocket infrastructure, rplidar_ros, realsense2_camera.

> **Scope note:** LiDAR (Tasks 1–3) and Camera (Tasks 4–6) are fully independent. Either section can be executed alone without the other.

```

Server -> Browser (camera frame, ~10 fps):
  {"type": "cam_frame", "data": "<base64_jpeg>", "ts": 1234.56}
```

```python
    @staticmethod
    def _summarize_scan(msg: LaserScan) -> dict:
        """Extract valid range stats from a LaserScan message."""
        valid = [r for r in msg.ranges
                 if math.isfinite(r) and msg.range_min <= r <= msg.range_max]
        return {
            'count':     len(valid),
            'range_min': round(min(valid), 3) if valid else 0.0,
            'range_max': round(max(valid), 3) if valid else 0.0,
        }
```

```python
    def _on_scan(self, msg: LaserScan) -> None:
        """Track LiDAR heartbeat and broadcast scan stats at ~1 Hz."""
        now = time.time()
        self._last_scan_time = now
        # Throttle WebSocket broadcasts to 1 Hz
        if now - self._last_scan_broadcast < 1.0:
            return
        self._last_scan_broadcast = now
        stats = self._summarize_scan(msg)
        payload = {
            "type":      "sensor_status",
            "sensor":    "lidar",
            "ts":        now,
            "count":     stats['count'],
            "range_min": stats['range_min'],
            "range_max": stats['range_max'],
        }
        self._loop.call_soon_threadsafe(self._broadcast_dict_sync, payload)
```

```python
import io

import numpy as np
```

Add this static method to `UIServer` (after `_summarize_scan`):
```python
    @staticmethod
    def _encode_image(msg: Image) -> str | None:
        """
        Convert a sensor_msgs/Image to a base64-encoded JPEG string.

        Supports rgb8 and bgr8 encodings. Returns None for unsupported encodings.
        """
        if msg.encoding not in ('rgb8', 'bgr8'):
            return None
        try:
            arr = np.frombuffer(bytes(msg.data), dtype=np.uint8).reshape(
                msg.height, msg.width, 3
            )
            if msg.encoding == 'bgr8':
                arr = arr[:, :, ::-1]  # BGR -> RGB
            buf = io.BytesIO()
            PILImage.fromarray(arr, 'RGB').save(buf, format='JPEG', quality=70)
            return base64.b64encode(buf.getvalue()).decode('ascii')
        except Exception:
            return None
```
