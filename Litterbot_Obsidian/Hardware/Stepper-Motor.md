# Stepper Motor

**Driver:** CL57T Closed-Loop Driver
**Application:** Linear extension/retraction of the scoop arms

## Role in Scooping Mechanism

The stepper drives both scoop arms forward (toward litter) and back (toward ramp) simultaneously. Full forward = scoop position; full retracted = litter deposited up the ramp into the collection bin.

Limit switches installed at both travel limits:
- **HOME** (PD15) — fully retracted position
- **EXTEND** (PE10) — fully extended position

Wired NC (normally closed) to GND with internal pull-up (fail-safe: wire break = triggered = stop).

**Calibration mode** (`C CALIBRATE\n` command): arm extends/retracts slowly counting steps, with B1 as latched e-stop. Step count is printed and hardcoded into `scoop_sequence.h`.

**Normal mode**: hardcoded step count drives the arm. Limit switches serve as passive emergency backup only — not load-bearing.

The servo bucket angle is intended to be a function of stepper position during the return stroke (coordinated motion). See [[Servo-Motor]].

## Specifications

- Model: NEMA 23 (23HS45-4204D-E1000)
- Supply: 24-48V
- Control: Step/Direction/Enable
- Encoder: Integrated 1000 CPR (to driver)

## Control Method

- Step pulse advances motor
- Direction pin sets rotation
- Driver handles position loop internally

## Implementation

**Files:** `cl57t_stepper.c/h`

**Peripherals:**
- GPIO bit-bang: PD14 (PUL+), PF15 (DIR+) — uses DWT cycle counter for microsecond delays
- No timer peripheral used — step pulses generated by software delay loop

## Timing

- Minimum pulse width: 2.5 µs
